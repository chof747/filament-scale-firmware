# Research: UI interaction

## Decision

No additional research required. Feature is already implemented; the only
pending changes are display refresh on scale change and initial weight render.

## Rationale

The existing code and agreed clarifications define the behavior sufficiently
for maintenance and the targeted updates.

## Alternatives considered

- Replacing the OLED UI layout: deferred to avoid scope expansion.
- Adding button multi-click patterns: deferred for simplicity.
